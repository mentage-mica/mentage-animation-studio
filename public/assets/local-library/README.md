# Local Asset Library

This folder is the local reusable production asset library for Mentage Animation Studio.

The heavy/licensed Adobe Stock and Figma import-kit files live here locally, but they are intentionally ignored by git so GitHub stays light and licensing-safe.

## Folders

- `adobe-stock/` - Original reusable Adobe Stock photos and vector files for Mentage production work.
- `figma-element-import-kit/` - Reusable Figma-ready Mentage visual elements exported from Adobe Stock sources.

## Rules

- Use these files for production graphics, video backgrounds, layouts, and Figma imports.
- Do not commit the original stock files unless the founder explicitly asks.
- Commit final public-safe outputs in the normal production folders when needed.
- Keep license notes and asset IDs visible in lightweight docs.

## Local Paths

- Adobe Stock originals: `public/assets/local-library/adobe-stock/`
- Figma import kit: `public/assets/local-library/figma-element-import-kit/`
